Configura captura automática

Para que el sistema lea las facturas directamente desde tu Gmail (en vez de tu registrarlas a mano), hay 3 pasos que se hacen una sola vez.

  1. Reenvío — agregas facturas@balanceclip.net en tu Gmail.
  2. Filtro — desde el correo de un proveedor real, creas un filtro de Gmail.
  3. ¡Listo! — las próximas facturas aparecen automáticamente en Pendientes.
💡 Puedes salir y volver — guardamos tu progreso.

Paso 1 — Reenvío

En Gmail, agrega esta dirección como reenvío. Avísanos por WhatsApp para aprobar el código y queda listo.

A
Copia esta dirección
facturas@balanceclip.net
B
Abre Gmail (web)
Abrir Gmail · Reenvío ↗
"Agregar dirección de reenvío" → pegar el email → Siguiente.
C
Avisa por WhatsApp
💬 WhatsApp ↗
Gmail enviará un código a la dirección. Lo aprobamos en menos de 1 hora.

Paso 2 — Filtro Gmail

Desde el correo de un proveedor real, creas el filtro una vez por proveedor.

1
Abre un correo del proveedor
Cualquier factura recibida sirve.
2
Menú ⋮ → "Filtrar mensajes de este tipo"
Gmail pre-llena el remitente automáticamente.
3
Marca "Tiene adjunto" → Crear filtro
Reenviar a: facturas@balanceclip.net → Crear filtro.
🔁 Repite por cada proveedor.

¡Listo!

De ahora en adelante, las facturas aparecerán en Registros → Pendientes listas para aprobar.

  • Para agregar otro proveedor, repite el Paso 2.
  • Si un proveedor genera mucho ruido, en ⚙ Configuración → Auto → Proveedores detectados lo desactivas.
  • El sistema sincroniza cada 15 min, o usa ↻ arriba para forzar.
✓ Ya no tienes que registrar facturas a mano.
