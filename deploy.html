Autenticación Google

Necesitamos tu token OAuth para crear el Google Sheet y la carpeta en Drive. El token queda solo en tu browser.

⚠️ Requisito: Google OAuth Client ID
Para que el popup de Google funcione, necesitas un OAuth Client ID configurado en Google Cloud Console con:
→ Tipo: Web application
→ Authorized JavaScript origins: file:// (si abres el HTML local) o tu dominio si está hosteado

Si no tienes uno, el campo de abajo acepta también un Access Token directo (más rápido para uso personal).
🔑

Autoriza con Google

El provisioner va a crear el Google Sheet y la carpeta de Drive en tu cuenta (o la cuenta que uses para el cliente).

sheets.spreadsheets drive.file script.projects script.deployments gmail.labels gmail.settings.basic
⚡ Auto-renovación de token (configuración una sola vez)
Cómo obtener el Refresh Token:
1. Abre OAuth 2.0 Playground
2. Ícono de engranaje → "Use your own OAuth credentials" → ingresa Client ID y Client Secret
3. Selecciona los scopes: spreadsheets · drive.file · script.projects · script.deployments · gmail.labels · gmail.settings.basic
4. "Authorize APIs" → "Exchange authorization code for tokens" → copia el refresh_token
