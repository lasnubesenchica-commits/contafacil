Autenticación Google

Necesitamos tu token OAuth para crear el Google Sheet y la carpeta en Drive. El token queda solo en tu browser.

⚠️ Requisito: Google OAuth Client ID
Para que el popup de Google funcione, necesitás un OAuth Client ID configurado en Google Cloud Console con:
→ Tipo: Web application
→ Authorized JavaScript origins: file:// (si abrís el HTML local) o tu dominio si está hosteado

Si no tenés uno, el campo de abajo acepta también un Access Token directo (más rápido para uso personal).

Autorizá con Google

El provisioner va a crear el Google Sheet y la carpeta de Drive en tu cuenta (o la cuenta que uses para el cliente).

sheets.spreadsheets drive.file script.projects script.deployments
⚡ Auto-renovación de token (configuración una sola vez)
Cómo obtener el Refresh Token:
1. Abrí OAuth 2.0 Playground
2. Ícono de engranaje → "Use your own OAuth credentials" → ingresá Client ID y Client Secret
3. Seleccioná los scopes: spreadsheets · drive.file · script.projects · script.deployments
4. "Authorize APIs" → "Exchange authorization code for tokens" → copiá el refresh_token
